# Product direction

Pyxis Discovery brings compound search, docking, molecular visualization,
molecule generation, and protein folding into one research workflow.

Improve the existing experience through focused, verifiable changes. Preserve
familiar controls and working signup, plans, billing, roles, companies, and
credits. “Pyxis-only” describes the product's branding; it does not retire those
capabilities.

The planned compute-service move should preserve application and scientific
contracts. The compute box does not receive the application API or its database.
Folding and molecule generation remain hosted services.

Prioritize reliable searches, clear results, and dependable viewer handoffs.
Broader changes—new scientific providers, binder-design workflows, authentication
migration, or large module rewrites—need an explicit product scope.
