--- title: What is substructure search? topic: cheminformatics order: 4 term: Substructure search summary: Substructure search finds every molecule in a library that contains a given fragment or pattern, such as a ring system or functional group. objectives: - Explain how substructure search differs from similarity search - Write simple SMARTS patterns - Understand why generic patterns are slow ---

A substructure search answers a yes-or-no question for each molecule in a library: does this molecule contain my query fragment? Unlike [pyxis_learn_link slug="what-is-tanimoto-similarity"]similarity search[/pyxis_learn_link], which ranks molecules by overall resemblance, substructure search returns every molecule that contains the pattern, however different the rest of the molecule is.

When to use it

  • Finding all compounds that share a hit's core scaffold, to explore what can change around it.
  • Pulling every molecule with a required feature, such as a warhead for [pyxis_learn_link slug="what-are-covalent-drugs"]covalent drugs[/pyxis_learn_link].
  • Filtering out unwanted groups (reactive or assay-interfering motifs).

Describing the query: SMILES and SMARTS

A simple query can be written as [pyxis_learn_link slug="what-is-smiles"]SMILES[/pyxis_learn_link] or drawn in a structure editor. For more control, chemists use SMARTS, a pattern language that extends SMILES with wildcards and logic:

SMARTSMatches
c1ccccc1A benzene ring
[#7]Any nitrogen atom, aromatic or not
C(=O)[NX3]An amide
[CX3]=[CX3]C(=O)NAn acrylamide

How it is computed

Checking whether one molecular graph is contained in another is a subgraph isomorphism problem. In the worst case it is expensive, so search engines use two stages:

  1. Screening. A [pyxis_learn_link slug="what-is-a-molecular-fingerprint"]fingerprint[/pyxis_learn_link] filter quickly discards molecules that cannot contain the query because they lack one of its features.
  2. Verification. An exact atom-by-atom match runs only on the survivors.

Specific queries — a distinctive ring system — screen out most of the library and return quickly. Very generic queries such as a single carbon chain match almost everything, so screening removes little and verification has to run on millions of molecules. Good search tools say clearly when such a search hit its time budget instead of silently returning partial results.
